A BETTER KIND OF GAMIFICATION

Help people move forward.

The goal is a better product experience.
Build the reward around that.

Read the pattern guide ↗
01

Value before vanity.

Reward a first useful result or meaningful collaboration. Pick actions that matter to the person doing them.

02

Always an open door.

Keep rewards optional. Let people skip, continue, and return without losing their place.

03

Real progress. Honest rewards.

A click is a beginning, not proof of completion. Verify the action and award credits once.

GET STARTED

Install Action Credits

  1. Download and extract the skill ZIP.
  2. Move the entire action-credits folder into ~/.codex/skills/. Keep an existing version if you have one.
  3. Open your app’s project in a new Codex chat and invoke $action-credits.
Use $action-credits to discover worthwhile reward actions for this SaaS and implement optional onboarding in our existing style.

The skill is plain Markdown. Other agents can read it too; their installation paths may differ.
