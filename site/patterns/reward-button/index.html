Reward Button

Give a meaningful action a clear beginning, an honest waiting state, and a small moment of reward.

Download component ↓ Download skill ↓

Try the button, or switch the next attempt to fail and explore its retry state.

Sandbox simulation. The delay and reward are illustrative; clicking this demo never issues product credits.

Three ways to fit

Raised for a primary action, compact beside content, or outline for a quieter reward.

Five honest states

Ready, pending, earned, error, and unavailable keep the outcome clear.

A useful finishing touch

For a completed lesson, a submitted task, or a reward already earned in your app.

Make the result feel good.

The button sends a request when selected. Your application starts the action or checks completion, then supplies the result. The raised version adds a little game-like press depth; the compact and outline versions fit more restrained surfaces.

Use an earned state only after the application confirms the result. If a request fails, keep the retry clear. If the action is unavailable, explain why in the surrounding interface.

Connect it to your application

Download the module, import it once, and add <reward-button> to your page. The reward-request event asks the host to act; it does not grant a reward or change the state automatically.

APPLICATION INTEGRATION
import './reward-button.js';

const button = document.querySelector('reward-button');
button.setAttribute('label', 'Claim lesson reward');
button.setAttribute('reward-label', '+25 XP');

button.addEventListener('reward-request', async () => {
  if (!['ready', 'error'].includes(button.status)) return;
  button.status = 'pending';
  try {
    // Your authenticated app verifies completion and grants once.
    const result = await requestExistingReward();
    button.status = result.status; // Authoritative component state.
  } catch {
    button.status = 'error';
  }
});

requestExistingReward() is your application adapter. It must resolve eligibility, reward amount, and duplicate requests through your existing service. The component displays the reward-label; that label never determines an actual award.

Set variant to raised, compact, or outline. Set status through its property or attribute. The font inherits from your page, and shared CSS variables let you match the rest of the app.
