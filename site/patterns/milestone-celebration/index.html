A quiet acknowledgment for everyday progress. A little more delight when someone reaches something special.

Choose the intensity

Inline for a small win, toast for an acknowledgment, or dialog for a moment worth pausing for.

No repeat fanfare

The same event ID is shown once per component instance until its demo history is reset.

Celebrate the real result

For a first project, a finished course, an earned badge, or a genuine level-up.

Match the moment.

Small, frequent wins work well inline or as a toast. Save a dialog for a substantial milestone that deserves focus. Keep the message specific: what happened, why it matters, and any reward already confirmed by your app.

The component remembers event IDs during its current lifetime. Use the replay control to see a duplicate ignored. Dismiss hides the celebration; Reset clears this local event history so you can explore again.

Connect it to your application

Import the module and add <milestone-celebration>. Call celebrate() with a stable event ID, title, description, and optional reward label. It returns whether a new celebration was accepted.

APPLICATION INTEGRATION
import './milestone-celebration.js';

const celebration =
  document.querySelector('milestone-celebration');
celebration.setAttribute('variant', 'toast');

// Your app supplies a confirmed milestone and a stable event ID.
const event = await getLatestUnseenMilestone();
if (event) {
  const shown = celebration.celebrate({
    id: event.id,
    title: event.title,
    description: event.description,
    rewardLabel: event.rewardLabel,
  });
  if (shown) {
    await recordMilestoneSeen(event.id);
  }
}

getLatestUnseenMilestone() and recordMilestoneSeen() are adapters to your application. Keep durable seen-state there when celebrations should stay dismissed across reloads, sessions, or devices. The component's event memory is local to one instance.

dismiss() hides the current presentation. reset() hides it and clears local event history. Use inline, toast, or dialog; the component does not create a milestone, grant its reward, or save account state.
