XP & Level Meter

Show how far someone has come, where they are now, and the next level within reach.

Download component ↓ Download skill ↓

Starting at 180 demo XP · Explorer.

Sandbox simulation. XP and level thresholds are examples, not a recommended scoring system. No score is stored.

Three useful shapes

A full progress bar, a compact summary, or a ring for a dashboard or profile.

Clear level thresholds

Current level and the next threshold are derived from the progress your app supplies.

Progress beyond points

For learning, practice, contributions, or any meaningful progression your product already measures.

A little context for every step.

Give the meter a total and an ordered set of level thresholds. It shows the current level and progress toward the next one. At the highest configured level, the experience has a clear finish instead of an impossible next target.

Try adding points to cross a level, subtracting them to preview a correction, and jumping to the highest level. These controls change only the demonstration.

Connect it to your application

Import the module and add <xp-meter> to your page. Supply a progress object with value and levels. Each level has a numeric threshold and a readable label.

APPLICATION INTEGRATION
import './xp-meter.js';

const meter = document.querySelector('xp-meter');
meter.setAttribute('variant', 'bar');

// Example data shape. Load production values from your app.
meter.progress = {
  value: 180,
  levels: [
    { threshold: 0, label: 'Beginner' },
    { threshold: 100, label: 'Explorer' },
    { threshold: 250, label: 'Builder' },
    { threshold: 500, label: 'Expert' },
  ],
};

// After a confirmed activity, replace the complete snapshot.
async function refreshProgress() {
  meter.progress = await loadMyProgress();
}

loadMyProgress() is your authenticated application adapter. Supply the existing scoring rules and latest total; the meter does not earn XP, save a balance, or unlock entitlements.

Use cumulative thresholds such as 0, 100, 250, and 500—not the amount required within each level. Choose bar, compact, or ring, then adapt the shared CSS variables to your app.
